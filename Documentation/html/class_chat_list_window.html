Detailed Description

ImGui window displaying the chat list and user search.

Shows two tabs: "Chats" (existing conversations with last message preview, status, and timestamp) and "Users" (server-side search for starting new chats). Supports manual refresh via refreshUsers(). All server calls are asynchronous and non-blocking.
