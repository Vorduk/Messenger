Detailed Description

TCP client for communicating with the messenger server.

Manages a single persistent TCP connection to the server. All network errors are handled internally - the caller receives an empty string or error JSON on failure.

Protocol format: Request: JSON + '
' Response: JSON + '
'

Blocks on sendRequest(). Designed as a building block for AsyncNetworkClient. Do NOT call from the UI thread directly.
